# شاشة مواقيت الصلاة — محافظة رابغ

واجهة شاشة مسجد تعمل بالكامل بدون إنترنت، تحسب مواقيت الصلاة لرابغ تلقائيًا كل يوم بطريقة تقويم أم القرى، وتعرض العد التنازلي للأذان والإقامة، وتبدّل الأذكار والأحاديث كل عشر ثوانٍ حسب الوقت.

---

## ما الذي تفعله الشاشة تلقائيًا

الوضع الطبيعي: الصلاة القادمة داخل المحراب مع العد التنازلي للأذان، والساعة والتاريخ الهجري والميلادي، وصف المواقيت الستة مع وقت الإقامة لكل صلاة.

عند الأذان: شاشة كاملة "حان الآن موعد أذان صلاة ..." لمدة ثلاث دقائق.

بين الأذان والإقامة: المحراب يتحول للأخضر الزمردي ويعد تنازليًا للإقامة، والأذكار تتحول لأحاديث فضل الانتظار والصف الأول.

آخر دقيقة: شاشة كاملة بعدّاد الثواني مع "استووا واعتدلوا" وتنبيه إغلاق الجوال.

عند الإقامة: شاشة "حان وقت إقامة صلاة ...".

أثناء الصلاة: الشاشة تصير شبه سوداء حتى لا تشتت المصلين.

بعد الصلاة: "تقبّل الله طاعتكم" مع أذكار بعد الصلاة لمدة ست دقائق، ثم ترجع الشاشة للوضع الطبيعي.

يوم الجمعة: الظهر يصير "الجمعة"، وبعد الأذان تظهر شاشة "خطبة الجمعة" بحديث الإنصات، ثم الصلاة.

الأذكار: من الفجر للظهر أذكار الصباح، ومن العصر للعشاء أذكار المساء، وبعد العشاء أذكار النوم وأدعية، وباقي الأوقات أدعية مأثورة، وكل ثالث عنصر حديث نبوي قصير، وليلة الجمعة ويومها تذكير بالجمعة.

رمضان: العشاء يتأخر تلقائيًا إلى ساعتين بعد المغرب حسب أم القرى.

آخر الليل: تعتيم تلقائي من الساعة ١١:٣٠ مساءً حتى قبل الفجر بأربعين دقيقة.

---

## ١. تشغيل المشروع من الفلاش

انسخ المجلد كاملًا إلى الفلاش بدون ما تغير أسماء الملفات أو أماكنها:

```
prayer-screen
```

لا تنقل ملف الصفحة الرئيسية لحاله، لازم المجلد كله مع بعض.

للتجربة على الكمبيوتر: افتح المجلد واضغط مرتين على الملف التالي، وبيفتح في المتصفح مباشرة:

```
index.html
```

---

## ٢. التشغيل على جهاز شاومي

```
Xiaomi TV Box S 3rd Gen
```

الخطوة الأولى: من متجر قوقل في الجهاز ثبّت متصفح:

```
TV Bro
```

وثبّت معه مدير ملفات، مثل:

```
X-plore File Manager
```

الخطوة الثانية: ركّب الفلاش في منفذ الجهاز.

الخطوة الثالثة (الأفضل والأثبت): انسخ المجلد من الفلاش إلى ذاكرة الجهاز الداخلية داخل مجلد التنزيلات، عن طريق مدير الملفات. السبب أن الفلاش ممكن ينفصل أو يتغير مساره بعد إعادة التشغيل، والذاكرة الداخلية أثبت.

الخطوة الرابعة: افتح المتصفح، واكتب في شريط العنوان المسار التالي:

```
file:///storage/emulated/0/Download/prayer-screen/index.html
```

ولو تبغى تشغله من الفلاش مباشرة، المسار يكون بهذا الشكل، والرقم يختلف حسب الفلاش وتشوفه من مدير الملفات:

```
file:///storage/XXXX-XXXX/prayer-screen/index.html
```

الخطوة الخامسة: لو طلب المتصفح صلاحية الوصول للملفات، وافق عليها. ولو ما فتحت الصفحة، روح لإعدادات الجهاز ثم التطبيقات ثم المتصفح ثم الأذونات، وفعّل الوصول للملفات.

الخطوة السادسة: احفظ الصفحة في المفضلة أو كصفحة البداية في المتصفح، عشان كل مرة يفتح عليها مباشرة.

الاتجاه: الصفحة مصممة بالعرض، والجهاز يطلع الصورة بالعرض تلقائيًا، فلا تحتاج أي تدوير.

---

## ٣. تعديل اسم الجامع

افتح الملف التالي بأي محرر نصوص (على الكمبيوتر يكفي المفكرة):

```
js/config.js
```

وعدّل هذا السطر:

```
name: "جامع الخير",
```

اكتب اسم الجامع بين علامتي التنصيص، واحفظ الملف.

---

## ٤. تعديل أوقات الصلاة

الأوقات تُحسب تلقائيًا لرابغ كل يوم، وما تحتاج تكتبها بنفسك.

لو لاحظت فرق دقيقة أو دقيقتين عن تقويم أم القرى أو عن أذان الجامع، عدّل قسم التصحيح في ملف الإعدادات. مثلًا لو المغرب عندك يطلع قبل الأذان الفعلي بدقيقة:

```
maghrib: 1,
```

والرقم السالب يقدّم الوقت.

ولو تبغى تكتب أوقاتًا ثابتة بنفسك، غيّر في قسم الأوقات اليدوية القيمة إلى صح، واكتب الأوقات بنظام ٢٤ ساعة:

```
enabled: true,
```

---

## ٥. تعديل أوقات الإقامة

في نفس ملف الإعدادات، قسم الإقامة بالدقائق بعد الأذان. القيم الحالية حسب المعمول به في مساجد المملكة: الفجر ٢٥، الظهر ٢٠، العصر ٢٠، المغرب ١٠، العشاء ٢٠.

ولو تبغى الإقامة على ساعة ثابتة (مثلًا العشاء الساعة ٨ دائمًا)، اكتبها في قسم الإقامة الثابتة:

```
isha: "20:00",
```

مدة الخطبة يوم الجمعة ومدة كل صلاة ومدة شاشة الأذان وشاشة بعد الصلاة كلها في قسم المدد في نفس الملف.

---

## ٦. تغيير الألوان

في نهاية ملف الإعدادات قسم الألوان، كل لون مكتوب بجانبه وش يمثل. غيّر الرمز السداسي للون واحفظ. مثال لتغيير الذهبي إلى ذهبي أفتح:

```
gold: "#D4B06A",
```

---

## ٧. تغيير الخط

الخطوط الحالية مدمجة داخل المشروع وتعمل بدون إنترنت: خط أميري للعناوين والأذكار، وخط آي بي إم بلكس العربي للأرقام والنصوص.

لتغيير الخط: ضع ملف الخط الجديد داخل مجلد الخطوط:

```
assets/fonts
```

ثم أضف في أول ملف التصميم هذا التعريف (غيّر الاسم واسم الملف):

```
@font-face { font-family: 'MyFont'; src: url('../assets/fonts/myfont.woff2'); }
```

ثم في نفس الملف عدّل متغير خط العناوين أو متغير خط الأرقام:

```
--font-display: 'MyFont', serif;
--font-ui: 'MyFont', sans-serif;
```

ملف التصميم هو:

```
css/style.css
```

---

## ٨. جعل الشاشة كاملة

داخل المتصفح افتح القائمة وفعّل وضع ملء الشاشة، أو اضغط زر الموافق في الريموت وأنت على الصفحة. الصفحة نفسها ما فيها أي تمرير أو أزرار، وتتكيف تلقائيًا مع دقة ١٠٨٠ ودقة ٤ كي.

---

## ٩. وضع التجربة

عشان تشوف كل حالات الشاشة بدون ما تنتظر، أضف وقتًا في آخر الرابط:

```
index.html?time=15:30
```

وهذا يجرب يوم جمعة:

```
index.html?time=2026-10-09T12:05
```

ولتسريع الوقت ستين مرة وتشوف الحالات تتبدل قدامك:

```
index.html?time=15:30&speed=60
```

يظهر شريط صغير أحمر أسفل الشاشة في وضع التجربة فقط.

---

## ١٠. ملاحظات مهمة للاستقرار

أوقف شاشة التوقف وتوفير الطاقة في الجهاز: الإعدادات ثم النظام ثم توفير الطاقة، واجعل إطفاء الشاشة على أطول مدة أو أبدًا. وكذلك عطّل شاشة التوقف أو الوضع المحيطي. هذه أهم خطوة.

الساعة: الشاشة تعتمد على ساعة الجهاز، فتأكد أن الوقت والتاريخ في الجهاز تلقائي من الشبكة. لو الجهاز بدون إنترنت دائمًا، اضبط الساعة يدويًا وراجعها كل فترة. المنطقة الزمنية ما تأثر لأن الحساب مضبوط على توقيت السعودية داخليًا.

التاريخ الهجري: يعتمد على تقويم أم القرى داخل المتصفح. لو اختلف يوم عن الإعلان الرسمي، عدّل قيمة التصحيح الهجري في ملف الإعدادات إلى ١ أو سالب ١.

الشاشة تعيد تحميل نفسها مرة يوميًا الساعة ٢:٣٠ فجرًا لضمان الثبات، وتتحرك حركة غير ملحوظة كل أربع دقائق لحماية الشاشة من بقاء الصورة.

للتشغيل التلقائي بعد انقطاع الكهرباء: المتصفح العادي ما يفتح الصفحة لوحده بعد إعادة تشغيل الجهاز. لو احتجت هذا، استخدم متصفح مخصص للشاشات يدعم التشغيل عند الإقلاع، مثل:

```
Fully Kiosk Browser
```

واجعل صفحة البداية فيه نفس المسار أعلاه.

بعد أي تعديل في ملف الإعدادات انسخه مرة ثانية للجهاز وأعد تحميل الصفحة.

## الصوت

كل إعدادات الصوت في ملف الإعدادات داخل قسم الصوت.

التنبيه: نغمة هادئة قبل الأذان بخمس دقائق، تشتغل حتى بدون إنترنت.

الأذان: يشتغل من يوتيوب أول ما يدخل الوقت، والمدة تتحدد برقم بداية ونهاية بالثواني. حط رقم المقطع في خانة الأذان.

التلاوة: تشتغل في أوقات الفراغ بالتناوب بين المقاطع، وتتوقف قبل الأذان بخمس دقائق، وترجع بعد انتهاء الصلاة وأذكارها.

أي زر في الريموت يوقف الصوت الحالي، ولو أوقفت التلاوة ترجع بعد الصلاة القادمة.

في متصفح الشاشة لازم تفعّل التشغيل التلقائي للصوت من إعدادات محتوى الويب، وإلا ما يطلع صوت.
